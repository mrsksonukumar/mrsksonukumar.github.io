## 🚀 Quick Start

### Local Development

1. Clone the repository:
    git clone https://github.com/mrsksonukumar/mrsksonukumar.github.io.git

2. Navigate to directory:
    cd mrsksonukumar.github.io

3. Open in browser:
   Simply open index.html in your browser
   Or use a local server:
   python -m http.server 8000

Then visit: http://localhost:8000


### Deployment

This site is automatically deployed via **GitHub Pages** whenever changes are pushed to the `main` branch.

## 🎨 Customization

### Colors

Edit CSS variables in `styles.css`:

:root {
--primary-color: #0ea5e9;
--secondary-color: #8b5cf6;
--accent-color: #f59e0b;
}


### Content

Update content directly in `index.html`:
- Profile information
- Project descriptions
- Skills and expertise
- Contact details
