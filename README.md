## 🚀 About

Personal portfolio website for **Sonu Kumar** - Data Analyst at Tesco's Property Insights team. Specializing in Python automation, SQL data engineering, and business intelligence.

**Live Site:** [mrsksonukumar.github.io](https://mrsksonukumar.github.io)

## ✨ Features

- 🎨 Modern, clean design with animated particle background
- 📱 Fully responsive (mobile, tablet, desktop)
- ⚡ Fast loading and optimized performance
- 🎭 Smooth scroll animations and transitions
- 💼 Project showcase with detailed case studies
- 📊 Interactive skill visualizations
- 🌐 SEO optimized

## 🛠️ Technologies Used

- **HTML5** - Semantic markup
- **CSS3** - Modern styling with CSS Grid & Flexbox
- **JavaScript (ES6+)** - Interactive functionality
- **Particles.js** - Animated background
- **AOS (Animate On Scroll)** - Scroll animations
- **Typed.js** - Typing animations
- **Font Awesome** - Icons
- **Google Fonts** - Typography
